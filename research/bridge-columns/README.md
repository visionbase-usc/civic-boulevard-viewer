## 入圖門檻

每一實體柱分列；保存原柱號（不可自行填補連號）、所屬主線／匝道、原圖圖號及版本、原始座標系及座標、街景連結及影像日期、查核日期。將墩號與單柱識別分開；同一墩多根柱不得合併計一根。沒有可靠柱位來源保持 geometry=null，不能採用相機座標、等距內插、示意圖比例推估或既有模型的假設墩位。
