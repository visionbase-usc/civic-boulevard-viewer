# 市民大道資料庫檢視器

研究範圍為**西至中山北路、東至光復南路**，僅發布原 S2–S4 的公開盤點資料及兩端路口必要關聯。依來源與確認程度查閱，不將資料筆數視為完整現況設施總數。

**網站：** https://visionbase-usc.github.io/civic-boulevard-viewer/

## 使用

- 開啟網站即可操作，無須登入或 API 金鑰。
- 「圖層」可任意切換六類資料及狀態；初始開啟停車場與車輛出入口。
- 分段選單與前後箭頭定位 S2–S4，右下「總覽」返回研究範圍。
- 點圖示查看公開來源、確認程度及關聯資料；聚合圓圈表示資料筆數，點擊放大。
- 「清單」保留沒有可靠座標的資料。「搜尋」跨所有分類與狀態查詢，選取結果會開啟對應圖層。
- 「分享」複製地圖位置、圖層、篩選、分段與選取資料的網址。

## 搬到其他電腦

從 GitHub 的 Code → Download ZIP 下載並解壓，直接用瀏覽器開啟 **`docs/index.html`**。JavaScript、樣式、Leaflet 與資料皆隨包提供；無須安裝 Node.js 或 Python。底圖為連網服務，離線時仍可查看資料及道路線形。分享功能產生正式網站網址，避免傳送個人電腦檔案路徑。

## 六類資料與來源

1. 停車場
2. 車輛出入口
3. 行人穿越／停車場行人入口
4. 公共運輸
5. 公共空間與服務
6. 機電維護

歷史與待確認為獨立資料屬性。歷史資料預設隱藏；啟用歷史顯示時包含其待確認事項。「待確認」開關篩選非歷史候選資料。部分官方資料仍有沿線歸屬、位置或現況待核，請以資料卡原始確認程度為準。

v1.5.0 收錄 356 筆分類資料及 29 個過街查找索引，共385筆，其中含137個行穿線圖形（含兩端邊界路口的完整關聯圖形）。圖形、分群、場站代表點、入口點、場站設備紀錄各有不同單位，**不可相加作為現況設施數量**。來源日期保留於每筆資料；資料查核日期為 2026-11-04。

- 停車場／入口／充電設備：臺北市停車場靜態資訊。
- 公車／YouBike／公廁／行穿線：各主管機關公開資料。
- 陸橋／地下街／公共空間／歷史設備：個別官方頁面或圖說。
- 完整來源索引：`docs/data/catalog.json` 與各筆原始欄位。
- PHOTO2 正射影像與 EMAP 電子地圖：國土測繪中心官方 WMTS。影像拍攝年代未核，請勿以查核日期當作拍攝日期。
- 道路線形：© OpenStreetMap contributors，ODbL；為參考線形，不是正式道路路界。

入口僅表示來源登錄位置，未推定出口或通行方向。沒有可靠座標的設備不在地圖上假設位置。行人穿越資料不代表自行車通行已確認。地下樓梯不標為電梯。沿用 S2–S4 編號，S2–S3 部分內部分段起訖仍待正式資料核對。

## 逐筆來源查核（v1.5.0）

全範圍385筆均有查核紀錄，包含356筆分類資料及29個派生查找索引。採用官方來源支持的內容，不以缺少街景為由否定官方資料；未知座標、來源本身的問題及完整性缺口另行說明。

點左上「i → 查看全部385筆查核結果」瀏覽；每張資料卡有查核摘要、核對欄位及來源值。可從說明面板下載 `docs/data/record-audit.csv`，385列逐筆追溯。

- 260筆資料紀錄逐欄比對重新下載的官方資料：29停車場、27登錄入口、10充電設備、137行穿線圖形、19YouBike、26公車站位、12公廁。
- 96筆以官方PDF或網頁核對：23地面樓梯口、15復敦既有圖說項目、35新增地面機電項目、3公共空間、5運動與活動場地、5公共藝術及10類完工工程項目。
- 29分群逐一檢查全部137個成員的唯一關聯，仍不算作正式路口數。
- 官方資料值與原盤點比對一致；19筆保留特定問題：1筆0,0入口、3筆可疑公車地址、4個行穿線圖形表達不足，以及4筆運動／活動場地問題、3筆公共藝術位置／年代疑義、4筆影像概略定位的入口精度限制。
- 97筆尚未採用地圖位置，仍可搜尋、閱讀來源及所屬場站；不以相機或停車場中心替代。

官方圖說地面樓梯口：中林4、林金7、建復4、復敦4、敦延2、延吉2，共23口。新生高架相關場站、其他沿線民營場站的完整行人入口清冊尚無充分來源；已建檔數不是範圍內所有實體設施的普查總數。

`source/official-records.json` 保留此次下載的相關官方原始列、SHP幾何與來源檔案SHA256；`source/document-audit.json` 保存逐項圖說／網頁觀察；`source/record-audit.json` 為可重跑的逐欄比對結果；原始盤點資料不覆寫。

## 橋下運動與沿線活動場地（v1.5.0）

新增兩處不同的滑板場、新生兩面籃球場（合一筆官方場館紀錄）、華山公園籃球設施及華山溜冰場／活動廣場，共5筆。新生滑板場已以2026-01場內360影像修正先前VBS登錄點；安東滑板場採2026-03場內360影像代表位置。兩者與官方場地照片交叉辨識，不是入口或測量界址。新生籃球場仍採VBS登錄點、保留來源差異；華山2筆仍未定位。華山公園內設施不一概稱為橋下設施。

`source/sports-sources.json` 保存場館原始欄位節錄、下載雜湊及人工觀察方式。VBS與iPlay的座標及籃球時段差異顯示於資料卡。安東段位置依官方照片與2024年會勘文件索引文字交叉判讀；原PDF本次下載404，未宣稱已目視查核PDF。華山溜冰場保留官方2026活動名稱，不據名稱推定現行運動功能。

這次補查確認先前來源涵蓋不足；已收錄紀錄逐筆查核不等於範圍內實體設施完整普查。

## 逐段覆蓋與位置證據（v1.5.0）

「i → 逐段覆蓋查核」按中林、林金、新生交會至建國、建復、復敦、敦延、延吉7個連續路段列出來源類型、關聯資料與具體缺口。這是持續查核清單，沒有宣稱每個路段已完整普查。

- 新增5筆官方公共藝術；「時間斑馬線」是藝術作品，歸公共空間，不歸行穿線。「合」與「時間斑馬線」官方文字／地圖有衝突，不採用問題座標。
- 新增工務局完工年報載明的10類橋下項目，含舞臺、座椅、照明、圍籬、入口遮板、噴灌、地坪、植栽及2類彩繪。每筆是工程項目類型，未知件數不推定為1件；無個別座標者保持未定位。
- `source/position-reviews.json` 保留場內觀察點、拍攝日期、影像連結與位置性質；兩視點概略套位另保留相機座標、方位、水平視角與人工目標像素，由 `scripts/positioning.py` 重現。相機／全景校正誤差未知，不把小數位數當成精度。
- `source/corridor-audit.json` 記錄逐段覆蓋；`source/public-art-sources.json` 保留藝術登錄欄位及被拒用的原始點；`source/corridor-source-manifest.json` 記錄來源及原圖預覽雜湊。
- 原圖預覽只在資料卡展開時載入；Google影像不打包或重新發布，資料卡連結回原頁。

## 更新資料

1. 更新 `source/inventory.json` 中的原始資料及查核日期，保留編號、來源連結、座標依據與待確認事項。
2. 道路線形快照分別保存在 `source/osm-roads.json` 。
3. 發布範圍由 `scripts/scope.py` 定義（S2–S4）；原始全線快照僅供追溯重建，不載入網站或可攜資料包。修改範圍或筆數時先執行 `python3 scripts/build_data.py --prepare-audit` 產生供查核使用的中間資料（不可發布），再更新官方來源擷取與圖說觀察、執行逐筆查核及正式重建；日常更新執行 `python3 scripts/audit_records.py`、`python3 scripts/build_data.py` 產出查核結果、瀏覽器資料包及來源索引。若筆數不同，建置會停止，避免套用舊範圍的查核。
4. 執行 `python3 -m unittest discover -s tests -v`，並用瀏覽器抽查變更位置與篩選。
5. 提交並推送至 `main`。GitHub Pages 設為 Deploy from a branch → `main` → `/docs`，自動發布。

既有版本重建只需 Python 3 標準函式庫。重新擷取官方快照可執行 `scripts/extract_official_audit.py SNAPSHOT_DIRECTORY`，此擷取步驟另需 pyshp、pyproj、shapely；下載目錄需含 parking.json、youbike.json、GetStop.gz、toilets.csv、crossings解壓目錄及下載雜湊manifest.json。使用網站不需要 Python。修改版本時同步更新轉換腳本的 `version`。不要直接修改產出的 `docs/data/inventory.js`。

## 實作

純靜態 HTML/CSS/JavaScript，Leaflet 1.9.4 隨包攜帶。網址 hash 保存檢視狀態，沒有登入、追蹤分析或資料寫入後端。資料與介面可在本機使用；第三方底圖僅按目前視窗載入，不大量快取或重製發布。瀏覽及圖磚限制在研究路廊周邊矩形範圍，留少量辨識周邊道路的邊距（非正式道路路界）；不預載全市、取消視窗外圖磚緩衝，拖曳與縮放停止後才更新底圖。透明路名圖層僅在街區尺度（zoom 15 以上）載入。

專案維護：VisionBase 市民大道專案團隊；程式及資料變更透過本 repo 的 commit／issue 管理。狀態見 `STATUS.md`。

## 2026-11-04 個案修正：G-017

使用者指出林金段停車場附近的枕木紋穿越點未完整表達。回查原始 SHP，C-08-7698 與 C-A8-7707 均距道路線不足 5 公尺，並非遭 35 公尺篩選排除；但兩筆原圖形只涵蓋小範圍，不代表完整穿越位置。兩筆 edittime 均為 2023-06-21。

已查看北側 2025-05、南側 2024-09 的 Google 地面街景，確認各拍攝時點可見枕木紋與中央步行空間。查核記錄獨立保存在 `source/reviews.json`，保留原始資料，於地圖增加 G-017 查核索引標記，不增加設施計數、不推估繪製完整邊界。完整街景連結與限制列於資料卡。

範圍內其他資料尚未逐點影像或現地核對。不能把來源下載日期、網站發布日期或程式驗收日期理解為範圍內現況查核日期。更新個案查核請編輯 reviews.json，再執行資料建置與測試。

## 行人入口資料維護

`source/pedestrian-access.json` 獨立保存文件頁碼、文件年代、地面入口是否明載、街景拍攝年月、查核日期及停車場關聯。`scripts/build_data.py` 合併新增資料；已有歷史樓梯沿用原編號並保留原始來源。

「圖層 → 停車場行人出入口 · 核對清單」可查閱範圍內23筆，均有地面層圖支持；公中與塔城5座樓梯已排除於本版範圍。林金段1–7號均附編號可辨的2024-09至2025-05街景（各口月份分列）；◎僅代表街景相機觀察點，不是入口座標。中林1–4號另有2022-03至2025-05編號影像與兩視點人工概略套位，地圖採空心待核標記；不是測量座標。23口皆可開啟官方原圖預覽；其餘19口geometry仍為null，不以相機點或場站中心替代。

查核範圍及各場缺口在資料卡與來源面板列出。範圍內橋下場站、出入口數量及現況尚未查核完成，不可將文件列示數當成完整現況數量。
