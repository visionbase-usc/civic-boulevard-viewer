- 由歷史樓梯開啟所屬停車場、入口及設備的關聯資料。

- 官方 PHOTO2、EMAP 圖磚正常載入；拖曳／縮放後才更新，keepBuffer=0、限制臺北周邊範圍。
- 模擬 WMTS 回傳 503：顯示重試／切換底圖，分段、資料清單與圖示仍可操作。

## 驗證限制

瀏覽器自動化工具禁止開啟 file://，因此未宣稱直接雙擊本機 HTML 已完成瀏覽器驗收；已檢查相對路徑、隨包資源及免 fetch 的資料載入方式，並完成本機 HTTP 預覽。Windows、Safari、Edge 未在本次環境實測。未完成現地勘查。
